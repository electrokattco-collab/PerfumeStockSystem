# 🌸 Perfume Stock Management System

## 📌 Overview

The Perfume Stock Management System is a Java-based application designed to help retail businesses efficiently manage their inventory. It allows users to track stock levels, manage product information, and maintain accurate records of perfume items in a store.

This project demonstrates core software development principles including data management, user interaction, and structured programming.

---

## 🎯 Features

* 📦 Add new perfume products
* 🔍 View and search available stock
* ✏️ Update product details
* ❌ Remove products from inventory
* 📊 Track stock quantities
